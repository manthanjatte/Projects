How to Run the Program
Make sure you have Python 3.x installed on your machine. You can download it from python.org.

Save the provided Python script as task_manager.py in a folder.

Open a terminal or command prompt, and navigate to the folder where the script is located.

Run the script using the command:python task_manager.py

Files Included
task_manager.py: The main Python script for the task management system.
tasks.db: SQLite database containing task data (this file will be generated automatically when the script is run).
